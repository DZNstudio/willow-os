# Willow OS

A studio operating system for a small creative team: one dashboard to run projects, clients, campaigns, the team, tools and design trends.

Built for the Foundation Ventures creative team (lead creative, marketing and project management) so the lead creative can run everything from a single home screen. It also hosts a client microsite and web deck for Coldstar under `/coldstar`.

## Pages
Home, Projects, Clients, Campaigns, Team, Tools, Trends, Ops.

## Run it
```bash
npm install
npm run dev
```
Next.js, TypeScript, Tailwind.
